Entry for the [make.fun bounty "The Meeting That Should Have Been One Line"](https://make.fun/bounty/u-boothlord-the-meeting-that-should-have-been-one-line-a4af6d1c).

## The line

> The only decision this meeting can make is when to schedule the next one.

One sentence, 73 characters. The meeting's only possible decision is to
schedule another meeting — so the meeting itself admits it produces
nothing, and after this line nobody can justify holding it at all.

## How it works

`main.py` (Python 3, stdlib only, deterministic) assembles the line from
its setup and punchline parts, validates it against the bounty gate
(UTF-8, 1–200 characters, not only whitespace, a single line), and writes
it to `/output/entry.txt`.
